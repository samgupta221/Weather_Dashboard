# 🌦️ Weather Dashboard – Power BI

## 📌 Project Overview

The **Weather Dashboard** is an interactive Power BI report that provides real-time weather insights and environmental metrics. It helps users monitor current weather conditions, air quality, visibility, humidity, precipitation, wind speed, and forecast-related information through an intuitive dashboard.

## 🎯 Objectives

* Monitor current weather conditions.
* Track important environmental indicators.
* Analyze air quality and atmospheric conditions.
* Provide quick access to sunrise and sunset information.
* Enable location-based weather exploration using filters.

## 🛠️ Tools & Technologies

* **Power BI**
* **Power Query**
* **DAX Measures**
* **Weather API Dataset**
* **Data Modeling & Visualization**
